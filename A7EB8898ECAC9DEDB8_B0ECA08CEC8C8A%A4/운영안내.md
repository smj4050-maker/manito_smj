# 울장복의 미니홈피 — 최종 운영 안내

모든 직원이 같은 주소를 사용합니다. 처음에는 본인 이름과 원하는 숫자 4자리를 등록하고, 사람 미니미 30종 중 하나와 별명을 고릅니다. 첫 입장에서만 배정된 마니또를 뽑기 연출로 확인하고, 다음부터는 바로 홈으로 들어갑니다. 방장 번호는 **3773**입니다.

## GitHub에 넣을 파일

압축을 풀고 최상위 **index.html 한 개만** 기존 GitHub 저장소 최상위의 index.html에 덮어씁니다. JavaScript, 스타일, 캐릭터·집·트리 이미지가 이 파일에 모두 들어 있습니다. source 폴더나 규칙 파일을 사이트에 올릴 필요는 없습니다.

1. **먼저 Firebase 규칙을 게시합니다.** Firebase → Firestore Database → 규칙에서 동봉한 **마니또_운영규칙.txt** 전체를 붙여 넣고 **게시**합니다. 이번 버전은 2시간 표시 기능 때문에 규칙 교체가 필요하며, 데이터는 삭제하지 않습니다.
2. GitHub 저장소 → Code → Add file → Upload files.
3. 압축 속 index.html을 기존 파일에 덮어쓰고 Commit changes 합니다. 파일 이름은 반드시 index.html입니다.
4. 기존 사이트 주소로 접속해 새로고침합니다. 변경이 보이지 않으면 배포 완료 후 Ctrl+F5를 누르거나 새 탭에서 엽니다.
5. 방장 → 3773으로 한 번 접속합니다. 기존 명단이 있다면 공통 로그인 설정이 자동으로 추가됩니다. 기존 배정을 유지하려면 랜덤 뽑기를 다시 누르지 않습니다.

공통 주소: https://smj4050-maker.github.io/manito_smj/

이번 변경은 index.html과 동봉한 Firestore 규칙을 함께 교체해야 적용됩니다. 예전 규칙으로는 미니미의 2시간 표시 시간을 저장할 수 없습니다. 기존 직원 명단·배정·계정·방명록·트리 글은 지우지 않습니다.

## Firebase 인증 설정

이미 했다면 다시 설정하지 않습니다. 프로젝트는 maniddo-efc9f이고 앱 데이터는 artifacts/manito-xmas-app에 저장됩니다.

Authentication → 로그인 방법에서 **익명**과 **이메일/비밀번호**를 사용 설정합니다. 직원 계정은 앱이 첫 등록 때 자동으로 만듭니다. 사진첩도 현재 Firestore를 사용하므로 별도의 Storage 설정은 필요 없습니다.

관리자 계정이 없다면 Authentication → 사용자 → 사용자 추가에서 한 번 만듭니다.

| 항목 | 값 |
|---|---|
| 관리자 내부 이메일 | admin@manito.invalid |
| Firebase 관리자 비밀번호 | manito-3773 |
| 사이트 방장 창에 입력하는 번호 | 3773 |

직원은 이메일을 입력하지 않습니다. 숫자 4자리는 Firebase 인증으로 확인하며, Firestore나 브라우저에 번호를 저장하지 않습니다. 0123처럼 0으로 시작하는 번호도 사용할 수 있습니다.

## 직원 입장

처음 방문: **처음 등록 → 등록된 본인 이름 → 원하는 4자리 번호 두 번 → 미니미·별명 선택 → 첫 마니또 확인 → 홈 입장**.

이후 방문이나 다른 기기: **로그인 → 이름과 등록한 4자리 번호**. 첫 마니또 확인 여부는 계정에 저장되므로 같은 배정에서 뽑기 화면이 반복되지 않습니다. 이전 버전에서 같은 브라우저에 남은 확인 기록도 이어받습니다.

새 회차를 배정하면 그 회차의 상대를 처음 한 번 확인합니다. 직원용 뽑기는 이미 정해진 상대를 보여주는 연출이며 배정을 다시 만들지 않습니다.

아직 등록하지 않은 다른 직원의 이름을 먼저 등록하는 행위는 이름만으로 자동 판별할 수 없습니다. 본인 이름으로 등록하도록 안내하고, 잘못 등록된 경우 방장이 확인 후 초기화합니다. 이미 등록된 이름은 기존 번호 없이 새 번호로 덮어쓸 수 없습니다. 4자리 번호는 간단한 활동용 잠금입니다.

## 홈과 연결된 2층 미니룸

- 제목은 울장복의 미니홈피, 방 이름은 울장복 미니룸입니다.
- 따뜻한 크리스마스 나무집의 1층과 2층이 하나의 화면에 이어집니다. 80명의 작은 미니미가 함께 보이고 왼쪽 계단을 실제로 오르내립니다. 미니미는 로그인하거나 저장된 로그인으로 사이트에 다시 들어온 때부터 2시간 동안 보입니다. 중간에 로그아웃해도 그 입장으로부터 남은 시간 동안 방에 남고, 시간이 지나면 모두의 화면에서 자동으로 사라집니다. 다시 로그인하거나 인증된 상태로 사이트를 다시 열면 2시간이 새로 시작됩니다. 단순 탭 전환·글 작성·미니미 수정만으로는 시간을 늘리지 않습니다. 접속 중/오프라인 상태나 마지막 로그인 시각을 화면에 표시하지 않습니다.
- 걷기만 반복하지 않고 잠깐 쉬기·앉기·손 흔들기·하트 보내기·깜짝 놀라기가 각자 다른 시간에 자동으로 나옵니다. 가까운 미니미끼리는 서로 인사하거나 장난치고 놀라는 반응을 주고받습니다.
- 벽난로 근처에서는 앉아 불을 쬐고, 책장 근처에서는 책을 읽고, 트리 앞에서는 잠깐 감상합니다. 각 행동이 끝나면 다시 돌아다닙니다. 80명 기준으로 이동할 때 서로 간격을 두고, 막히면 기다리거나 비켜갑니다. 표시되는 2시간 동안의 모션은 장식용 자동 동작이며 다른 직원에게 실제 업무 중 행동을 보내지 않습니다.
- 벽난로 불꽃·전구·촛불과 주변의 따뜻한 빛이 은은하게 일렁입니다.
- 미니미는 트리 뒤로 지나갈 때 나뭇가지에 가려지고, 앞을 지날 때는 트리 앞에 보입니다. 기기에 동작 줄이기가 켜져 있으면 두 층에 정지해서 표시되며 2시간 표시 시간은 똑같이 적용됩니다.
- 배경은 약 48% 농도로 연하게 표시하고 채도를 낮춥니다. 트리와 미니미는 원래 색을 유지합니다. 방 높이를 늘리고, 미니미는 인원이 적을 때 기존의 약 2.15배, 80명일 때 약 1.4배로 표시합니다. 인원에 맞춰 개인 공간도 조절합니다.
- 걷기는 몸통과 양쪽 다리를 나누어 발을 번갈아 내딛는 모션으로 표현합니다. 길이 막혀 기다릴 때는 제자리걸음 대신 쉬는 자세가 나옵니다.
- 미니미를 누르면 별명이 보입니다. 내 미니미 버튼에서 캐릭터와 별명을 바꿀 수 있습니다.
- 휴대폰에서는 방 전체를 작게 맞춰 보이고, 확대 보기로 넓게 살펴볼 수 있습니다.
- 본문 전체가 세로로 스크롤됩니다. 방명록은 위쪽 탭으로 옮겨 홈 아래의 좁은 칸을 없앴습니다.
- 발도장 기능은 제거했습니다. 활동 진행과 일촌평은 기존처럼 사용할 수 있습니다.

## 함께 꾸미는 입체 트리

1층 정중앙의 큰 트리는 처음엔 장식 없는 나무입니다. **큰 트리에 크리스마스 한마디 달기**를 누르고 160자 이내의 글, 장식 모양과 색을 고르면 나뭇가지에 장식이 하나 달립니다. 글이 없으면 공용 트리에 장식도 없고, 글 1개에 장식 1개씩 생깁니다. 배경 장식과 공용 트리 장식은 별개입니다.

한 사람당 장식 하나를 사용합니다. 다시 쓰면 내 장식과 글이 바뀌며, 내 장식을 삭제하면 나무에서도 사라집니다. 기존에 작성된 글은 새 배경에도 그대로 장식으로 표시됩니다. 장식을 누르면 그 사람이 남긴 글이 보이고, 꾸미기 창 아래에서는 모든 한마디를 모아 볼 수 있습니다. 장식과 글은 다른 직원 화면에도 공유됩니다.

## 사진첩

사진첩 탭에서 사진과 500자 이내의 글을 올립니다. 사진만 또는 글만 올릴 수도 있습니다. 사람 미니미와 별명으로 표시되는 공용 대화 공간입니다. 사진을 누르면 크게 보고 저장할 수 있습니다.

사진은 기기에서 작은 JPEG로 압축한 뒤 업로드합니다. 원본은 최대 15MB이며 저장되는 사진은 약 165KB 이하로 줄입니다. 동영상은 지원하지 않습니다. 처리할 수 없는 사진 형식은 JPG 또는 PNG로 바꿔 골라주세요.

자신이 올린 글은 자신이 삭제할 수 있고, 방장은 모든 사진첩 글을 삭제할 수 있습니다. 처음에는 최근 30개를 불러오며, 이전 글 더 보기로 최대 최근 150개까지 볼 수 있습니다.

## 방명록과 NEW

홈의 **나를 챙기는 마니또의 소식**에는 실제 활동 알림, 최근 방문 알림 시간, 받은 일촌평 수와 NEW가 표시됩니다. 나를 챙기는 사람이 **활동 진행!**을 눌렀을 때 다녀간 소식으로 기록됩니다. 단순 로그인이나 실제 접속 중 상태를 표시하지 않습니다. **내 소식 보기**를 누르면 나에게 온 방명록과 활동 소식만 모아 볼 수 있습니다.

방명록 탭에 일촌평과 활동 소식을 모았습니다. **내 마니또 소식**을 누르면 나를 챙기는 마니또가 내게 남긴 일촌평과 다녀간 소식만 보입니다. 정체 공개 전에는 작성자의 정체가 드러나지 않습니다. 일촌평 쓰기는 본인에게 배정된 상대에게 글을 남깁니다.

사진첩·방명록에 새 글이 생기면 해당 탭에 NEW가 표시됩니다. 해당 탭에서 글을 확인하면 본인 계정의 읽은 기록이 저장되어 표시가 사라집니다. 다른 직원의 읽음 기록은 볼 수 없습니다.

사진첩과 트리 한마디에는 별명이 표시되고, 마니또 일촌평은 공개 전까지 익명으로 표시됩니다.

## 조회수와 음악

TODAY는 한국 시간 기준 오늘 방문 수, TOTAL은 누적 방문 수입니다. 이 버전 적용 후부터 실제로 집계하며 기존의 고정 숫자 71/1225는 이어 쓰지 않습니다. 페이지를 열거나 새로고침하면 1회 올라가고, 같은 페이지에서 로그인하거나 탭을 바꾸는 것만으로 중복 집계되지 않습니다. 누가 방문했는지는 카운터에 저장하지 않습니다.

음악줄의 **▶ 재생**을 누르면 선택한 YouTube 영상 q-ZFpbrokMg가 재생됩니다. 큰 영상 화면은 펼치지 않고, 같은 버튼이 **Ⅱ 일시정지**로 바뀝니다. 다시 재생하면 이어 듣고, 홈·사진첩·방명록 탭을 바꿔도 재생을 유지합니다. 앱 브라우저가 첫 재생을 막으면 한 번 더 누르라는 안내가 나옵니다. 실제 음원 재생 가능 여부는 YouTube의 제공 상태와 브라우저 정책에 영향을 받습니다.


## 방장 관리

| 기능 | 동작 |
|---|---|
| 번호 초기화 | 기존 번호 접근 권한을 해제하고 공통 주소에서 새 번호를 등록하도록 합니다. 미니미·배정·활동 기록은 유지합니다. |
| 미니미 초기화 | 캐릭터·별명과 첫 뽑기 확인부터 다시 진행하도록 합니다. 로그인 번호·배정·선물 상태·게시물은 유지합니다. |
| 제출 완료자 옆 삭제 | 선물 준비 완료 표시를 취소하고 미제출자로 이동합니다. 구성원은 유지됩니다. |
| 구성원 수정·삭제 | 이름이나 인원이 바뀌면 기존 배정을 해제합니다. 명단 확정 후 다시 배정해야 합니다. |
| 마니또 정체 공개 | 공개하는 동안 참가자가 전체 배정과 작성자 정체를 볼 수 있습니다. 공개를 중지하면 서버에서도 다시 제한합니다. |

번호 초기화 전의 Firebase 인증 계정은 관리 콘솔에 남을 수 있지만 앱 데이터 접근 권한은 해제됩니다. 수동으로 일괄 삭제할 필요는 없습니다.

## 검증과 원본

별도 Firebase 에뮬레이터와 실제 브라우저에서 권한 제한, 로그인·초기화·첫 확인 기록, 80개 미니미의 연결된 두 층 표시와 계단 이동·트리 앞뒤 가림, 공유 글과 사진, 개인별 NEW, 트리 장식, 홈의 익명 방문 소식, 실제 조회수를 검증했습니다. 2시간 만료·재입장 시 갱신, 서버 시간 검증과 다른 사람의 표시 시간 변경 차단을 확인했습니다. 별도 80명 시뮬레이션을 300초 실행해 11종의 자동 상태·짝 인사와 장난·벽난로/책장/트리 행동·개인 공간 비겹침을 확인했습니다. 음악은 API를 모의한 재생·일시정지·차단 후 재시도와 화면 크기 유지를 확인했으며 실제 스트리밍 음원을 청취한 검증은 포함하지 않습니다. 테스트는 실제 운영 데이터에 기록하지 않습니다.

source 폴더는 수정 가능한 원본이며, 캐릭터 PNG 데이터와 표시 좌표는 avatars.js, 집 배경과 투명 트리 PNG는 room-background.js, 자동 행동과 간격 조절 로직은 house-motion.mjs에 들어 있습니다. 캐릭터 생성 방식과 프롬프트는 character-generation.md에 정리했습니다. 이 폴더에서 npm install 후 npm run build를 실행하면 상위의 index.html이 만들어집니다.
